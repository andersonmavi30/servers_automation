# Servers Automation

🇨🇴 [Español](README.es.md)

Multi-platform automation projects focused on **Linux Server Administration, Infrastructure Automation and DevOps practices**.

This repository is intended to develop and document automation workflows for the administration, configuration, validation and operation of Linux server infrastructure using repeatable and version-controlled processes.

## 🎯 Project Objective

The goal of this repository is to build reusable automation solutions for common Linux server administration tasks, reducing repetitive manual work, improving configuration consistency and applying Infrastructure as Code and DevOps practices to system administration.

## 🐧 Platforms

The project is designed to progressively cover:

- **Red Hat Enterprise Linux (RHEL)**
- **Rocky Linux**
- **AlmaLinux**
- **Ubuntu Server**

Additional Linux distributions may be incorporated as the repository evolves.

## 🔧 Technology Focus

Automation will progressively use technologies such as:
