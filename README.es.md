# Automatización de Servidores

🇺🇸 [English](README.md)

Proyectos de automatización multiplataforma enfocados en **Administración de Servidores Linux, Automatización de Infraestructura y prácticas DevOps**.

Este repositorio está orientado al desarrollo y documentación de flujos de automatización para la administración, configuración, validación y operación de infraestructura Linux mediante procesos repetibles y versionados.

## 🎯 Objetivo del Proyecto

El objetivo de este repositorio es construir soluciones de automatización reutilizables para tareas comunes de administración de servidores Linux, reduciendo trabajo manual repetitivo, mejorando la consistencia de configuración y aplicando prácticas de Infrastructure as Code y DevOps a la administración de sistemas.

## 🐧 Plataformas

El proyecto está diseñado para cubrir progresivamente:

- **Red Hat Enterprise Linux (RHEL)**
- **Rocky Linux**
- **AlmaLinux**
- **Ubuntu Server**

Podrán incorporarse distribuciones Linux adicionales a medida que el repositorio evolucione.

## 🚀 Áreas de Automatización

El repositorio incorporará progresivamente automatización relacionada con:

- Aprovisionamiento del sistema operativo

- Gestión de servicios
- Administración de sistemas de archivos y almacenamiento
- Configuración de red
- Configuración de firewall
- Hardening del sistema
- Validación de baselines de seguridad
- Gestión de parches
- Actualizaciones del sistema
- Backups de configuración

- Validación de configuración

- Operaciones sobre múltiples servidores

## ⚙️ Enfoque de Automatización

El objetivo a largo plazo no es únicamente crear scripts o playbooks individuales, sino aplicar una metodología estructurada de **DevOps y Automatización de Infraestructura a la administración de servidores Linux**.

```text
Git
 │
 ▼
Validación
 │
 ▼
Automatización
 │
 ▼
Servidores Linux
 │
 ▼
Post-check
 │
 ▼
Reportes / Remediación
```

Este enfoque permite administrar infraestructura Linux mediante flujos repetibles, versionados y auditables.
